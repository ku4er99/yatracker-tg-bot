# Анализ процесса

ИИ помог быстро сопоставить Telegram Bot API и API Трекера, собрать отдельные HTTP-клиенты, тесты и CI/CD. Ошибка первого варианта проявилась в тесте: `System.Text.Json` не читал дату Трекера с часовым поясом `+0000`. После исправления добавлен тест с реальным форматом ответа. Независимый Critic заметил ложную ошибку при повторном нажатии кнопки страницы; исправление также покрыто тестом. Следующим улучшением pipeline будет обязательный контрактный тест на сохранённом обезличенном ответе внешнего API до написания интерфейса. Живую проверку нельзя заменять моками: после появления секретов отдельно проверить выдачу Трекера, Telegram и контейнер на сервере.
