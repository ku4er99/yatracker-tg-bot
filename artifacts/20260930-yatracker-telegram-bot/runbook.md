# Запуск и восстановление

1. Создайте бота и OAuth-доступ по README, добавьте 8 GitHub Actions Secrets.
2. После PR и merge в `main` убедитесь, что job `verify`, затем `deploy` зелёные.
3. На сервере: `cd ~/telegram-bot && docker compose ps && docker compose logs --tail=100 bot`.
4. Проверьте в личном чате `/start`, кнопку «Задачи на мне», следующую страницу и неверный текст.
5. При ошибке проверьте имена секретов, ID организации/тип `cloud` или `360`, текущий пароль SSH и доступ к Docker.
6. Для отката верните предыдущий проверенный commit отдельным PR в `main`; после merge workflow повторит деплой.

Секреты лежат в GitHub Actions Secrets и на сервере в `~/telegram-bot/.env` с правами `600`. Их нельзя выводить в журнал или добавлять в архив проекта.
