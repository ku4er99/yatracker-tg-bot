# Вопросы и решения

- Поле сортировки: пользователь выбрал дату обновления, свежие сверху.
- Токен BotFather и OAuth-токен Трекера ещё не созданы; пользователь добавит их в GitHub Secrets по инструкции.
- ID организации Трекера и её тип пока неизвестны; README содержит шаги получения.
- Временный пароль учебного сервера из исходного файла может быть уже сменён. В GitHub Secret нужен текущий пароль; он не записывается в репозиторий.
- Живая проверка Telegram/Трекера зависит от этих данных.
