# AI-005 — финальный проект

## Что делает бот

Личный бот показывает открытые задачи, назначенные владельцу OAuth-токена Яндекс Трекера. Кнопка «📋 Задачи на мне» открывает по 10 задач, сортировка — обновлённые недавно сверху. В сообщении есть ссылки на карточки, статус и время по Москве. Доступ ограничен одним Telegram user ID и личным чатом. `/start` показывает меню, неправильный ввод и ошибка API дают понятный ответ.

## Проверки и Critic

`dotnet build -c Release` выполнен успешно без предупреждений; `dotnet test -c Release` — 7 тестов пройдено. Docker-образ собран локально. Проверены `/start`, основной сценарий, переход страницы, неправильный ввод, запрет чужому пользователю, ошибка Трекера, формат API и экранирование текста. Независимый Critic не нашёл блокирующих дефектов; его замечание о повторном нажатии страницы исправлено и покрыто тестом. PR #1 в `main` прошёл GitHub Actions `verify`; job деплоя пропущен до merge. Для обеих веток включены и проверены правила: PR и успешный `verify` обязательны, включая администратора.

## Текущие ограничения и процесс

Реальные BotFather/Яндекс Трекер пока не проверены: токен бота, OAuth-токен и ID организации ещё не предоставлены через Secrets. Пароль SSH должен быть текущим после смены временного; в репозиторий он не включён. Поэтому работающий релиз нельзя заявлять до успешного деплоя и ручной проверки в Telegram.

ИИ ускорил реализацию интеграций и тестов, но сначала пропустил формат даты `+0000`; тест выявил это до релиза. Следующий раз стоит добавить контрактный тест ответа внешнего API раньше, а для Critic — отдельную проверку UX и настроек GitHub. Подробные артефакты процесса: `artifacts/20260930-yatracker-telegram-bot/`.
