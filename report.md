# AI-005 — финальный проект

## Что делает бот

Личный бот показывает открытые задачи, назначенные владельцу OAuth-токена Яндекс Трекера. Кнопка «📋 Задачи на мне» открывает по 10 задач, сортировка — обновлённые недавно сверху. В сообщении есть ссылки на карточки, статус и время по Москве. Доступ ограничен одним Telegram user ID и личным чатом. `/start` показывает меню, неправильный ввод и ошибка API дают понятный ответ.

## Где код и документация

Репозиторий: https://github.com/ku4er99/yatracker-tg-bot. README содержит инструкции по BotFather, OAuth Трекера, локальному запуску и GitHub Secrets; пример настроек — `.env.example`.

## Проверки и Critic

`dotnet build -c Release` выполнен успешно; `dotnet test -c Release` — 8 тестов пройдено. Проверены `/start`, основной сценарий, переход страницы, неправильный ввод, запрет чужому пользователю, ошибка Трекера, формат API, экранирование текста и отсутствие `parse_mode: null` в запросе Telegram. Независимый Critic не нашёл блокирующих дефектов; его замечание о повторном нажатии страницы исправлено и покрыто тестом. PR #9 прошёл `verify`; [запуск после merge](https://github.com/ku4er99/yatracker-tg-bot/actions/runs/36718428981) успешно выполнил `verify` и `deploy`: контейнер пересоздан и запущен, Telegram `getMe` определил `@YaTrackerTasksBot`, поиск задач Трекера вернул OK. Пользователь подтвердил, что задачи пришли в чат. Для обеих веток действуют правила: PR и успешный `verify` обязательны, включая администратора.

## Текущие ограничения и процесс

Первая живая проверка обнаружила HTTP 400 от Telegram из-за сериализации `parse_mode: null` и HTTP 403 от Трекера из-за настроек OAuth/организации в GitHub Secrets. После исправления запроса Telegram и настройки секретов обе проверки прошли. Сборка Docker на сервере зависала при чтении контекста на машине с 1 ГБ памяти; теперь образ собирается на GitHub runner и передаётся на сервер по SSH. Значения секретов не входят в репозиторий и журнал. Ручная проверка выдачи задач выполнена; переключение страниц покрыто автоматическим тестом.

ИИ ускорил реализацию интеграций и тестов, но сначала пропустил формат даты `+0000`; тест выявил это до релиза. Следующий раз стоит добавить контрактный тест ответа внешнего API раньше, а для Critic — отдельную проверку UX и настроек GitHub.
